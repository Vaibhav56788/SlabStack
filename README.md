# 🎧 Slabstack — 3D Music Player

A visually immersive, browser-based music player built using **HTML, CSS, and JavaScript**. Slabstack transforms the traditional music-list experience into an interactive 3D collection of music albums, combining creative design with functional audio playback.

Explore your music library through a 3D album stack, upload your own audio files, manage your queue, and enjoy a unique listening experience.

---

## ✨ Features

### 🎵 Music Playback
- Play and pause audio tracks.
- Previous and next track controls.
- Interactive playback progress bar.
- Seek to any position in a song.
- Volume adjustment and mute controls.
- Audio visualization.

### 📚 Music Library
- Upload individual audio files.
- Upload multiple audio files.
- Add songs to your music library.
- Search songs by title, artist, or year.
- View and manage your music collection.
- Add or change album cover artwork.

### 🎼 Queue Management
- Add songs to the playback queue.
- Remove songs from the queue.
- Clear the entire queue.
- Add all library songs to the queue.
- Automatically queue longer songs based on your settings.

### 🔀 Playback Options
- Shuffle mode.
- Repeat all tracks.
- Repeat a single track.
- Adjustable minimum song duration.

### 🎨 Interactive Design
- Unique 3D album-stack interface.
- Animated album interactions.
- Detailed album information view.
- Responsive visual elements.
- Dark aesthetic with immersive lighting effects.
- Custom music-player controls.

## 🚀 Getting Started

Follow these steps to run Slabstack on your computer.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/music-player.git
```

### 2. Open the project folder

```bash
cd music-player
```

### 3. Run the application

Open the `index.html` file in your browser.

Alternatively, open the project in Visual Studio Code and use the **Live Server** extension.

### 4. Start listening

- Open the music library.
- Upload your audio files.
- Select a track.
- Use the playback controls to enjoy your music.

## 🔒 Privacy

Slabstack processes user-selected audio files locally in the browser using the Web Audio API.

The application does not require users to upload their personal music files to a music-hosting server for local playback.

Player preferences such as volume and playback rules are stored using browser Local Storage.
